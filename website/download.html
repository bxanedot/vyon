CHOOSE YOUR PLATFORM

One player. Your screen.

Get the installer that matches your operating system. Availability changes by release.

Windows

Look for an EXE, MSI or MSIX installer in the official GitHub releases. Explore desktop playback options.

macOS

Check published DMG or PKG installers and supported system requirements in releases. Learn more about vyon for desktop.

Linux

Look for supported AppImage, DEB or RPM packages in releases. Packaging and architecture availability vary.

Android

Look for an Android APK in releases. Visit the Android guide for offline listening and device features.

BEFORE INSTALLING

Official downloads and updates.

Only install files published by the vyon project. If there is no build for your device yet, don't assume one is available.

  1. Open the official releases page.
  2. Check the release notes and find an installer for your operating system and architecture.
  3. Follow the installation prompts on your device. Android may request permission to install an APK from your browser.
  4. Return to the releases page for updates or consult common questions.
