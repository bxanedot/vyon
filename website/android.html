ANDROID INSTALLATION

How to get the official APK.

Get files only from the project's published release page. A release may not contain an Android build.

  1. Open the vyon GitHub Releases page.
  2. Check for a compatible Android APK and review release notes.
  3. Install using Android's on-screen prompts; your device may ask for APK installation permission.
  4. For updates, check the latest releases or use an in-app updater when your build offers one.
GOOD TO KNOW

Android and beyond.

The repository also contains an Android TV experience and a Wear OS companion. These are distinct device experiences; check current builds and requirements before installing.

vyon is an independent app using YouTube Music as a backend. It is not an official Google or YouTube Music application. Tracks and downloads depend on available sources.
