# Authentic vyon icons

Place the preferred **original vyon icon image** at `website/icons/originals/vyon-icon.png`.

- Preserve the original artwork and colors. A square PNG with transparency is recommended.
- The homepage's rotating icon and its small header logo will load the PNG automatically.
- Until that file exists, the current vyon `/favicon.svg` is used as a visual fallback.
- The interactive spin operates at a 30% baseline, accelerates to 80% when clicked, and smoothly returns to 30%.
- Images embedded only in the conversation are not accessible as repository file bytes to the GitHub integration; please provide file attachments for exact placement.
