GOOD TO KNOW

Questions,
answered.

The essentials about vyon, YouTube Music, and Android downloads.

What is vyon?+

vyon is an Android music player that uses YouTube Music as its backend, with its own interface for listening. It isn't a separate music hosting service.

Where can I download vyon?+

Use Download APK at the top of this page. When a stable Android APK has been published, the button links directly to the file on GitHub Releases, without a separate download page. If no stable APK is available, the button will tell you.

How do I install the APK?+

Download the official APK on your Android device, open the file, and follow Android's installation prompts. Your device may ask you to allow installations from the app you used to download it.

How do I get updates?+

Check the project's GitHub Releases for newer stable APKs. Install a newer compatible, correctly signed APK over your existing installation using Android's normal update prompts.

Is vyon available on iOS or desktop?+

vyon currently targets Android APKs. There is no iOS or desktop download offered on this site.

Is vyon an official YouTube Music app?+

No. vyon is a separate project that uses YouTube Music as its backend. It is not presented as an official YouTube Music application.
