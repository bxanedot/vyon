GOOD TO KNOW

Questions,
answered.

The essentials about vyon, supported devices, downloads, and updates.

What is vyon?+

Vyon is a music player for Windows, macOS, Linux, and Android. It uses YouTube Music as its backend with its own listening interface; it does not host music itself.

Where can I download vyon?+

Choose your device in the Downloads section. Verified stable installers link directly to their files on GitHub Releases. When none is available or the release cannot be verified, you can browse the releases page.

How do I install vyon on my device?+

Use the official release file for your operating system: Windows (EXE, MSI, or MSIX), macOS (DMG or PKG), Linux (AppImage, DEB, or RPM), or Android (APK). Follow your system’s installation prompts. Android may ask permission to install files from your browser.

How do I get updates?+

Download the latest official release for your platform from GitHub Releases. Android users can also use the in-app updater when available.

Which platforms does vyon support?+

Vyon supports Windows, macOS, Linux, and Android. iOS and iPadOS are not supported. Check Downloads for available installers.

Is vyon an official YouTube Music app?+

No. vyon is a separate project that uses YouTube Music as its backend. It is not presented as an official YouTube Music application.
