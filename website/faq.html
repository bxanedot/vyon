COMMON QUESTIONS

About vyon.

These answers describe current project capabilities; the latest release notes are the source for build-specific availability.

What is vyon?+

vyon is a cross-platform music player for Windows, macOS, Linux and Android. It uses YouTube Music as a backend but is an independent project, not an official YouTube Music app.

Where can I download vyon?+

Use the downloads section on vyon.live or the official GitHub Releases page. Available installers depend on the latest published release.

Which systems does vyon support?+

vyon targets Windows, macOS, Linux and Android. The project also includes Android TV and a Wear OS companion. iOS and iPadOS are not supported.

Can I listen to downloaded music offline?+

On supported Android and desktop builds, tracks already downloaded to your device can be played offline. Download sources and file formats vary.

How can I update vyon?+

Check GitHub Releases for the latest official installer for your platform. Some Android builds also provide an in-app updater.

Can I download full albums or playlists?+

Supported Android and desktop builds include options to queue an album, an artist page's available track listing or a playlist for download. Availability depends on the source.

Is vyon an official YouTube Music or Google application?+

No. vyon is an independent player powered by YouTube Music, not an official app from Google or YouTube.

Does vyon support lossless audio or Dolby Atmos?+

Compatible sources, tracks, devices and decoders can enable higher-quality playback, including supported lossless formats and Dolby Atmos paths. Neither is guaranteed for every song or platform.

Does vyon have an equalizer?+

vyon includes audio controls such as an equalizer and presets, with available capabilities varying by platform.

Where can I report a problem or request a feature?+

Open an issue in the public bxanedot/vyon GitHub repository and include your platform, build version and steps to reproduce.
