# Distribution availability

The official website links to installers only after they appear as verified assets in a published GitHub release.

Do not install or redistribute unsigned Android release APKs. A signed APK must pass Android's package signature verification before publication.

Desktop packages are produced by platform-native Gradle tasks. The first release must verify the native libraries and launch behavior on Windows, macOS, and Linux before those installers are advertised.

Bulk album, playlist, and artist catalog downloads are deferred. The supported download flow in this release scope is for individual tracks.
