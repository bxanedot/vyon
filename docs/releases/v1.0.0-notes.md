# vyon 1.0.0

The first Vyon release brings together the Android, Android TV, Wear OS, and desktop music player under one identity.

- Music discovery, library, lyrics, and playback across supported devices.
- Local music and individual-track offline downloads.
- An optional YouTube video mode.
- Listen Together room support.
- Platform installers and signed Android packages.

Album, playlist, and artist catalog downloads are deferred.
