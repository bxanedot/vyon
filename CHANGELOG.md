# Changelog

User-facing changes to vyon are recorded here.

## v1.0.0 — 2026-10-17

This is the first Vyon release line, built from a fresh product identity.

- Android, Android TV, Wear OS, Windows, macOS, and Linux project targets.
- Music and local playback, discovery, library, lyrics, and platform-specific playback controls.
- An optional YouTube video mode alongside music playback.
- Listen Together client support using the configured Cloudflare service.
- GitHub-based release updates and version display.

Bulk album, playlist, and artist catalog downloads are deferred and are not part of this release.
